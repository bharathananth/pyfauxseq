# Python Implementation of the R package fauxseq

![PyPI version](https://img.shields.io/pypi/v/pyfauxseq.svg)
[![Documentation Status](https://readthedocs.org/projects/pyfauxseq/badge/?version=latest)](https://pyfauxseq.readthedocs.io/en/latest/?version=latest)

This package can generate synthetic rhythmic timeseries RNAseq datasets.

* PyPI package: https://pypi.org/project/pyfauxseq/
